# Zenodo deposit instructions

Use the Software resource type for the versioned repository release. Include the source ZIP, main manuscript PDF, supplementary PDF, graphical abstract, and checksum file.

Use `.zenodo.json` and `CITATION.cff` as the canonical metadata sources. Reserve the DOI, add it to the manuscript and repository metadata, regenerate the package, and then publish the record.

The release contains derived coding, bounded metric inputs, schemas, tests, figure and table generators, and LaTeX source. It excludes a verbatim forum corpus and contributor handles.

Publish version `0.1.0`. Future data or claim changes require a new version and changelog entry.
