# Manuscript build

The main manuscript targets the structure expected for an SLAS Technology Original Research submission and uses Elsevier's `elsarticle` class.

```bash
make paper
make supplement
```

`make paper` and `make supplement` first refresh `build/results.json`, the figures, and the generated tables, so they need the Python environment (`uv sync --all-extras`).

## Building without Python

The vector figures consumed by LaTeX are committed, so a fresh clone with only a TeX distribution can compile the manuscript:

```bash
make paper-only
cd paper && latexmk -pdf -interaction=nonstopmode -halt-on-error supplement.tex
```

`paper/figures/*.pdf`, `paper/graphical_abstract.pdf`, `paper/graphical_abstract.png`, and `paper/generated/*.tex` are tracked and are regenerated byte-identically by `make figures`, `make graphical-abstract`, and `make tables` on the locked environment. Only the raster previews `paper/figures/*.png` are untracked. `tests/test_build_outputs.py` fails if the committed tables drift from a fresh build.

Submission support files:

- `main.tex` and `sections/`
- `supplement.tex`
- `highlights.txt`
- `cover_letter.tex`
- `graphical_abstract.png`
- reproducible figures under `figures/`
- generated LaTeX tables under `generated/`

The main manuscript contains five figures and two tables. Direct code counts and the AI validation funnel are placed in the supplement, keeping the main submission at seven combined figures and tables. The supplement also documents the hard-case adjudication set (`data/derived/reliability_subset.csv`), which prepares an independent second coding pass without reporting an agreement statistic that the single-coder pilot cannot support.

## Claim traceability

Every approved claim in `data/derived/publication_claim_ledger.csv` carries a `% claim: Cxx` marker next to the passage it supports and a `Manuscript anchor` substring that must appear in that passage. Run `make claims` (or `make validate`) after editing claim wording; the check fails if a claim loses its manuscript binding.
